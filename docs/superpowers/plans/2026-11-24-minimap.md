# Locator map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a cached 2D north-up locator in the lower left, driven by `params.json` masses and the live Walk / Fly / Orbit pose.

**Architecture:** `web/minimap.js` owns the schematic, the projection and the canvas. `web/main.js` only fetches `params.json`, builds a pose and calls `sync`. The plan bitmap is rebuilt when the canvas size changes. The WebGL canvas stays the first canvas in the document.

**Tech Stack:** ES module, 2D canvas, Node assertions, Playwright, the existing Pages copy step.

## Global Constraints

- Branch `cursor/v14-minimap-d908` from `main` `2c030c5d94d46292e58467f305ce2ef28cf0867d`. Do not merge or deploy.
- North up, south down. The map stays visible in every mode.
- Walk uses feet and `player.yaw`. Fly uses the camera and `fly.yaw` and says `飞行`. Orbit says `环绕` and draws no player.
- No click teleport. `pointer-events: none`.
- Outline numbers come from `params.json`. Do not treat `spaces.json` probes as a plan and do not print room names.
- Yaw `0` points north. Yaw `π/2` points west.
- Off-frame subjects become an edge tick, not a dot at the building centre.
- Floor index `L{i}` only when the reported height is within `0.4 m` of a `4.5 m` level.
- Desktop map `172×148` at `12` px inset. Narrow and short viewports use `132×114` and `112×96`.
- Map backing-store ratio at most `2`. Render cap stays `1`. Clay cap stays `2`.
- No new WebGL context, no extra 3D pass, no per-frame mesh walk, no per-frame `innerHTML`.
- Ship `minimap.js` and `params.json` in `dist/` and fail the pack check if either is missing or hashed differently.
- Do not resume the arch-edge change, do not cut window openings, do not run `sync_gh_repo.py`.
- Blender is absent, so Cycles, silhouette and streamline checks are not run.
