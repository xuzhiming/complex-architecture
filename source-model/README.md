# Source model

Original editable Blender scene and its uncompressed glTF export, stored as received.

- `building.blend` — editable Blender file, 2,946,023 bytes.
- `building.glb` — uncompressed glTF binary of that scene, 11,081,340 bytes.

These files do not include the later web preview look. Daylight textures, transparent glass, and the other runtime materials are applied in the page, not in these binaries. The site still loads `web/building_opt.glb`.
